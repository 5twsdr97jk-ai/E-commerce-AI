# Quickstart: Starty (Setup & Koppelen)

**Wat je doet:** zip in Claude slepen → typ **Start** → klaar. Geen aparte prompt.

**Wat je krijgt:** Starty koppelt 4 tools (Shopify, WinningHunter, Apify,
Higgsfield) - een micro-stap tegelijk - en bouwt daarna je DSA Business-profiel.

## Zo start je

1. Download de agent (zip) via de pagina.
2. Gebruik **Claude Code** (niet alleen de gewone chat/Co-work) - zie install.html.
3. Sleep het zip-bestand in Claude en typ precies:

```
Start
```

Meer hoef je niet te typen. Geen "lees alle bestanden", geen "installeer skills",
geen eigen uitleg. Starty neemt het over in het Nederlands.

## Wat de agent doet

1. Stelt zich voor (kort) en noemt de 4 tools.
2. Koppelt ze micro-stap voor micro-stap - jij klikt / plakt alleen wat hij vraagt:
   - **Shopify** - nieuw account → `.myshopify.com` → CLI → Theme Access → login
   - **WinningHunter** - account → 20k-credits-plan → API-key
   - **Apify** - account → API-token
   - **Higgsfield** - account → custom connector → nieuwe chat
3. Stelt daarna 4 korte vragen (type, doel, niche, markt).
4. Levert je profiel + volgende-agent-advies.

## Handig om bij de hand te hebben

- Tijd voor een nieuw, leeg Shopify-account (betalen hoeft niet)
- Node.js + Shopify CLI 4.x (Starty loodst je erdoorheen)
- Even ruimte om per tool een account + sleutel te maken

Je deelt nooit je Shopify-wachtwoord. Overslaan mag; zeg het gewoon.

## Gebruik dit NIET voor

- Losse analyses of content (gebruik de specifieke agent)
- Store/campagnes wijzigen (Starty zet alleen je setup klaar)
